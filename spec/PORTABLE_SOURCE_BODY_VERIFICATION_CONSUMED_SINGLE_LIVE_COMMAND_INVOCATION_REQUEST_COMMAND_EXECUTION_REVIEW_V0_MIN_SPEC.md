## 4. Definitions

`command_execution_review` means review of selected consumed request basis and selected execution-review-boundary basis to determine whether one command execution review result may be recorded. It is basis review only. It is not command invocation, command execution, command output, command result, command success, execution permission, execution approval, command invocation authorization, authority, currentness, final completion, continuation, reusable permission, derivative reception, vessel relation, another reception request, or follow-on work.

`execution_review_result` means the bounded record that a command execution review was recorded, not recorded, required additional basis, or was blocked. It is not command output, command result, command success, execution permission, execution approval, or command invocation authorization.

`reviewed_consumed_request_basis` means the consumed one-shot request basis selected for review. It remains closed consumed-request basis. It is not reopened and is not execution permission or command success.

`reviewed_execution_review_boundary_basis` means the recorded consumed-request command execution review boundary selected for review. It is boundary basis only. It is not actual command execution review by itself and not execution permission.

`execution_review_passage` means bounded passage through this review membrane as a review result only. It does not permit command invocation or command execution.

`execution_review_recorded` means one command execution review result has been recorded from the selected basis. It does not create command invocation, command execution, command output, command result, command success, execution permission, execution approval, or command invocation authorization.

`execution_permission` means permission to invoke or execute the command. This specification creates no execution permission.

`execution_approval` means approval that a command may be invoked or executed. This specification creates no execution approval.

`command_invocation_authorization` means authorization to create command invocation. This specification creates no command invocation authorization.

`command_invocation` means causing a command module, function, script, shell, CLI, workflow, or comparable execution surface to run. This specification does not create command invocation.

`command_execution` means the actual live run or execution event of the command. This specification does not perform command execution.

`command_output` means output emitted by a separately authorized live command invocation. This specification creates no command output.

`command_result` means a result object produced by separately authorized live command execution. This specification creates no command result.

`command_success` means successful command execution, successful return, exit status, passed execution check set, or comparable success posture from a later live run. This specification creates no command success.

`standing_invocation_lane` means any durable or reusable posture that would allow command invocation without a separately bounded review. This specification creates no standing invocation lane.

`repeat_invocation_permission` means any permission to reuse the consumed request, invoke more than once, or treat one consumed request as reusable authorization. This specification creates no repeat invocation permission.

`consumed_request_token_closed` means the consumed request token remains closed after one clean consumption. It must not be consumed again, reused as repeat permission, reopened, or converted into a standing invocation lane.

`review_non_claim` means an explicit false posture preserved to prevent command execution review from being overread as command invocation, command execution, command output, command result, command success, execution permission, execution approval, command invocation authorization, authority, currentness, final completion, continuation, reusable permission, derivative reception, vessel relation, another reception request, or follow-on work.
