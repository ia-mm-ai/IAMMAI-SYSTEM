`artifact_as_source` means treating artifact existence, path, report, or carrier copy as source standing. This boundary forbids that collapse.

`result_as_authority` means treating command result or boundary result as authority. This boundary forbids that collapse.

`success_as_currentness` means treating command success as currentness or final completion. This boundary forbids that collapse.

`consumed_request_token_closed` means the consumed request token remains closed and is not reopened by this boundary.

`authorization_token_reuse_blocked` means the spent one-shot authorization token remains blocked from reuse, revival, or respawn.
