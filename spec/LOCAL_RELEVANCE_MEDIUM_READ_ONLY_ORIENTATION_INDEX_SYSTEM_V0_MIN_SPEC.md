## 4. Definitions

`orientation_index` means the read-only local lookup object, not source authority, truth, currentness, action, or runtime permission.

`deterministic_local_lookup` means lookup by declared local keys only, not search.

`already_standing_orientation_locator_entry` means an index entry already recorded before this system; no new entry is accepted here.

`first_orientation_locator_entry` means the first local relevance orientation index entry.

`second_orientation_locator_entry` means the second local relevance medium second local relevance orientation index entry.

`read_only_state_packet_artifact` means the selected artifact containing the basis read-only state packet.

`first_locator_artifact` means the artifact for the first local relevance orientation index entry.

`second_locator_artifact` means the artifact for the second local relevance medium second local relevance orientation index entry.

`first_orientation_view_artifact` means the artifact for the first relevance orientation view.

`second_orientation_view_artifact` means the artifact for the second relevance orientation view.

`lookup_key` means one declared stable key such as first/second received signal id or first/second locator role.
