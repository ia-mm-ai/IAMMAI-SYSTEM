## 1. Purpose

This specification defines one minimum operation for evaluating one exact already-admitted receiver-originating declaration as source for exactly two receiver-allocated modal conditions:

- `receiver_answerable_basis_refusable`
- `receiver_answerable_basis_could_have_been_withheld`

The operation is downstream of one completed source-admissibility boundary that recorded `RECEIVER_ORIGINATING_MODAL_FACT_EVALUATION_CONSIDERATION_ALLOWED`. It performs one matter-specific source-support evaluation only.
