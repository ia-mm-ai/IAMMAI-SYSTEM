## 4. Definitions

`command_output_containment` means one bounded containment event over the possibility of command output downstream of recorded execution and output containment boundary. It is not command output, output capture, command output/report artifact, command result, command success, source, authority, currentness, final completion, continuation, reusable permission, derivative reception, vessel relation, another reception request, or follow-on work. It may preserve basis for a future command output step.

`bounded_command_output_containment_event` means one recorded containment event under the selected command output containment boundary basis. It is containment posture only and does not create command output, output capture, command output/report artifact, command result, command success, source, authority, currentness, final completion, continuation, reusable permission, derivative reception, vessel relation, another reception request, or follow-on work.

`command_output_containment_boundary_basis` means the clean command output containment boundary result and terminal-summary basis recording that one bounded command execution event and audit-only execution trace are preserved for one future command output containment step. It is not command output containment, command output, output capture, command output/report artifact, command result, or command success.

`recorded_command_execution_event` means the bounded post-invocation command execution event recorded downstream of recorded command invocation and post-invocation command execution boundary. It is execution-event posture only and is not command output, output capture, command output/report artifact, command result, command success, source, authority, currentness, or final completion.

`execution_trace` means audit-only evidence that a bounded execution event was recorded. Execution trace is not command output, output capture, command output/report artifact, command result, command success, source, authority, currentness, final completion, continuation, reusable permission, derivative reception, vessel relation, another reception request, or follow-on work.

`command_output` means content emitted or captured by a separately bounded command output step. Command output containment is not command output, and execution trace is not command output.

`output_capture` means capture of stdout, stderr, process output, command output body, or equivalent output content. This specification does not create output capture.

`command_output_report_artifact` means an artifact that reports, stores, packages, or presents command output from a live execution. This specification does not create a command output/report artifact.

`command_result` means a separately bounded result object or result posture after output has been reviewed, interpreted, shaped, or carried forward. Command output containment is not command result.

`command_success` means a separately bounded success posture, successful execution determination, accepted exit-status posture, or equivalent success claim. Command output containment is not command success.

`output_as_source` means command output being treated as source standing. Output must not become source by command output containment, containment boundary, capture, artifact existence, path posture, or narration.

`result_as_authority` means command result being treated as authority. Result must not become authority by command output containment, containment boundary, artifact existence, path posture, or narration.

`success_as_currentness` means command success being treated as currentness, public readiness, final completion, continuation, or equivalent closure. Success must not become currentness or final completion.

`consumed_request_token_closed` means the consumed request token remains closed after one clean request consumption. It must not be reopened by command output containment, command output containment boundary, execution trace, command output, result, success, artifact existence, path posture, or narration.

`authorization_token_reuse_blocked` means the spent one-shot command invocation authorization token remains unavailable for second use, repeat use, standing use, durable permission, replay, re-consumption, token revival, token respawn, or reuse posture.

`output_containment_non_claim` means an explicit false posture preserving that command output containment did not create command output, output capture, command output/report artifact, command result, command success, source, authority, currentness, final completion, continuation, reusable permission, derivative reception, vessel relation, another reception request, or follow-on work.
