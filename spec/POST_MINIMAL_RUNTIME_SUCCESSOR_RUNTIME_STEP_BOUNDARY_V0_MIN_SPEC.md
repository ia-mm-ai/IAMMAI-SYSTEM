## 4. Definitions

`minimal_runtime` means one bounded runtime step posture only, already recorded as single-step posture.

`bounded_runtime_result_or_refusal` means the recorded minimal-runtime result/refusal posture from selected standing basis; it does not authorize successor action.

`successor_runtime_step_boundary` means a future bounded posture, if separately resolved and recorded, that may state whether one successor runtime step may later be approached.

`runtime_hosting` means hosted execution capacity beyond one bounded step. It is not created here.

`ongoing_runtime` means continuing runtime beyond a bounded single step. It is not created here.

`source_transfer` means transfer of source-standing material. It does not occur here.

`reception_authorization` means authorization to receive material as source or standing basis. It is not created here.

`currentness` means operative current standing. It is not created here.

`follow_on_work` means authorized successor work, continuation work, runtime work, source/reception work, deployment work, publication work, or governance work beyond this boundary. It is not authorized here.
