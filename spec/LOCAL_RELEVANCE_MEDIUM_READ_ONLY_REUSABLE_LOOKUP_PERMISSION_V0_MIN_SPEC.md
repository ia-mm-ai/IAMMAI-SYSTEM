# Local Relevance Medium Read-Only Reusable Lookup Permission V0 Minimum Specification

## 1. Purpose

This file defines one local relevance medium read-only reusable lookup permission for the present `IAMMAI-SYSTEM` execution line.

This is a permission specification after reusable lookup permission boundary. This permission is based on one clean reusable lookup permission boundary and one clean lookup-pair coverage artifact.

This permission allows repeated read-only deterministic lookup only over the two already-covered supported lookup keys:

- `first_orientation_locator`
- `second_orientation_locator`

This file creates one bounded reusable read-only lookup permission only.

This file does not create general lookup permission. This file does not create arbitrary lookup permission. This file does not create new lookup result or new lookup entry.

This file does not create registry, search surface, query surface, ranking surface, scoring, priority, validity judgment, truth judgment, authority, currentness, or runtime permission.

This file creates no repeated reception permission, arbitrary reception, or feed.

This file accepts no new entries. This file accepts no new signals. This file creates no new relevance objects. This file creates no new index entry. This file performs no filesystem discovery.
