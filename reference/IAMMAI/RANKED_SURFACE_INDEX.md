# IAMMAI Ranked Surface Index

## 1. Purpose

This file is a cross-rank navigation surface for the repository as it stands now.

Its job is to help a reader move cleanly across the repo’s ranked surfaces without collapsing root lineage, constitutional rank, `v1/` derivation, executable proof, readability artifacts, and additive threshold entries into one flat list.

It does not define:

- a rewrite of `CURRENT_STATE__REPO_ENTRY.md`
- a rewrite of `CONSTITUTIONAL_VERSION_NOTE.md`
- a rewrite of `START_HERE__VERSION_MAP.md`
- a rewrite of any `v1/` account entry
- a constitutional rewrite
- a standing declaration
- a manifesto
- a project-management roadmap

This file is additive. It does not replace earlier entry or rank-specific surfaces.

## 2. How To Read This Repository

The shortest truthful reading is:

- root remains the frozen source-side lineage body
- constitutional surfaces remain separately ranked within `protocol/`
- `v1/` is the later admissible derivation line
- preserved runs under `v1/registry/runs/` are proof-bearing evidence
- snapshot and report artifacts under `v1/registry/snapshots/` and `protocol/snapshots/` are readability surfaces

This repository should not be read flatly. Different surfaces do different work, and later readability surfaces do not erase earlier lineage or source-side rank.
