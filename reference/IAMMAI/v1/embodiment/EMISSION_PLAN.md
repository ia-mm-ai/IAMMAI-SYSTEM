# IAMMAI v1 Emission Plan

## 1. Purpose

This file defines the bounded v1 embodiment-level emission plan that follows the current runtime law and precedes concrete emitter re-derivation.

Its job is to state what the first v1 emission round is supposed to emit, in what order, and under what layer distinctions, without becoming code and without pretending continuity is already settled.

It does not define:

- a constitutional rewrite
- a seam declaration
- an authority or inheritance map
- an artifact-boundary decision
- a schema file
- a validator code note
- an emitter implementation patch
- a continuity redesign
- a runbook for human operators
- a storage topology design
- a project-management roadmap
- a README

It is a bounded embodiment plan.

## 2. Why This Plan Is Needed Now

V1 now has canonical body schemas, conformance posture, and runtime flow.

That means emitter re-derivation should not begin without an embodiment-level emission plan. The body now has enough law to say what the first v1 emission round is supposed to form, check, optionally carry, preserve, and interpret.

The current root emission behavior remains historically real v0 lineage evidence. The root runners and their emitted outputs show what the body actually did under the v0 line, including run-saturated identity and continuity handling. That evidence is important. It is not automatic v1 emission law.

## 3. First Principle

Embodiment emission must emit what has been lawfully formed.

Body comes before envelope.  
Envelope comes before preservation.  
Later carrying or preservation must not redefine artifact law.

In v1 terms, embodiment must not begin from a combined runtime bundle and then infer a canonical artifact body from whatever happened to travel with it. Canonical body must first stand as canonical body.

## 4. Scope of the First v1 Emission Round

The first v1 emission round is centered on the currently re-derived canonical body families:

- validation artifact
- witness artifact
- governance action
- transition record
- state record

This first round is intentionally bounded. It exists to establish ordinary v1 artifact emission under the current body law.

Continuity-turn is explicitly out of scope for this first round. Continuity remains a special case under the current v1 line and requires later handling that respects the present v1 separation between body, envelope, and preservation.

## 5. Emission Layers

The first v1 emission round distinguishes three embodiment-level output layers:

- canonical body output
- optional envelope-bearing emission output
- preservation or registry output

Canonical body output is the emitted artifact as artifact.

Optional envelope-bearing emission output is the lawful case in which a canonical body may travel together with explicit execution or envelope context while remaining separable from it.

Preservation or registry output is the preserved result of placing already formed output into authoritative preservation context.

These layers may appear in one embodied run. They must not collapse into one undifferentiated output surface.

## 6. Ordered Emission Path

The lawful order of the first v1 emission round is:

1. canonical body formation  
2. canonical body conformance  
3. optional envelope-bearing emission formation  
4. envelope-bearing conformance  
5. preservation placement  
6. preservation conformance  
7. fixture interpretation where relevant

Embodiment must follow this order rather than collapse it.

Canonical body formation and canonical body conformance come first because the artifact must stand as canonical body before combined carrying can be judged.

Envelope-bearing emission, where present, comes later because combined carrying is downstream of body standing rather than a substitute for it.

Preservation placement and preservation conformance come later again because preserved placement must not redefine what the artifact is.

Fixture interpretation comes after the relevant conformance surface because fixture meaning depends on what stage and layer were actually exercised.

## 7. First Proof Slice

The first bounded proof slice should be small and decisive.

At minimum, it should contain:

- at least one positive lawful path
- at least one bounded negative or refusal-path example
- enough emitted structure to prove that v1 can form and carry artifacts without re-collapsing body, envelope, and preservation

The positive path should demonstrate the ordinary v1 stage order for the in-scope artifact families.

The bounded negative or refusal-path example should demonstrate that failure can remain explicit at a specific stage or layer without being misread as total architectural incoherence.

This first slice does not settle the whole body. It is the first bounded proof that ordinary v1 emission can proceed without immediately falling back into v0 collapse patterns.

## 8. Current-v0 / Desired-v1 Distinction

Current root runners and outputs are historically real v0 lineage.

They show the actual root embodiment path in which artifact ids, emitted bodies, preservation outputs, and continuity handling remain tightly coupled to run occurrence.

The desired v1 emission plan is the target posture that later emitter work must serve. This is not blame language. It is the explicit statement that v1 embodiment is being re-derived rather than silently inheriting the root run-saturated posture by convenience.

## 9. Continuity Boundary

Continuity-turn remains outside this first emission round.

Continuity requires later special handling consistent with current v1 law. It remains a special case because execution occurrence still matters more directly there than in the ordinary canonical body families already re-derived.

Embodiment must not silently smuggle continuity back into ordinary artifact emission by convenience. The first ordinary v1 emission round is for the five re-derived canonical body families only.

## 10. Anti-Collapse Rules

A conforming first v1 emission round must not allow:

- envelope-first emission posture
- preservation-first artifact posture
- combined output that destroys body or envelope recoverability
- reuse of v0 run-saturated posture by convenience
- continuity shortcut inside the first ordinary emission round

It must also not allow positive proof to be claimed from preservation alone, from combined travel alone, or from fixture visibility alone. Each stage must stand in its own order.

## 11. Downstream Consequences

Later emitter re-derivation must follow this emission plan.

Later fixture generation must follow this emission plan. Later transfer-account entries should reflect this emission plan where relevant.

This file is therefore the embodiment bridge from runtime law into controlled emitter work. It keeps the first v1 emission round bounded enough to support proof without re-importing the root line’s unresolved saturation.

## 12. Closing Boundary Statement

This file defines the bounded emission plan only.

Later files or implementation work may realize this plan in emitter surfaces. This plan exists so v1 can move into emitter re-derivation without re-importing v0 collapse patterns.
