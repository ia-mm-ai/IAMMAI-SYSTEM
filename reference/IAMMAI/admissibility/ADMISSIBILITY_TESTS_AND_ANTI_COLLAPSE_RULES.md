# IAMMAI Admissibility Tests and Anti-Collapse Rules

## 1. Purpose

This file defines the bounded operational review membrane for admissibility inside the IAMMAI body.

Its job is to make explicit the core tests and anti-collapse rules that should be reviewed whenever candidate material, a source, a transition, a claim, or standing-facing pressure is being treated as admissible in some bounded way.

It does not:

- rewrite the constitutional protocol
- rewrite constitutional Acceptance
- rewrite `runtime/VALIDATOR_CONTRACT.md`
- rewrite `admissibility/SOURCE_ADMISSIBILITY.md`
- rewrite `admissibility/CANON_AND_STANDING_ADMISSIBILITY.md`
- define a canon admission procedure
- declare standing
- define a runtime flow map
- define a source-selection implementation patch
- act as a README, manifesto, or project-management note

This file is additive. It does not replace existing constitutional, runtime, v1, continuity, or admissibility surfaces. It operationalizes a review posture across them without becoming their sovereign substitute.

## 2. Why This File Is Needed Now

The admissibility layer has now been mapped.

The repository therefore now needs a bounded operational review membrane so that admissibility is not left as atmosphere.

That need is practical because the current body is dense enough that:

- convenience can counterfeit admissibility
- proof-bearing visibility can counterfeit admissibility
- readability can counterfeit admissibility
- admissible derivation can counterfeit final closure
- preserved lineage can counterfeit standing admission

If explicit review questions are not preserved, the body can begin to read as though visibility, preservation, proof, or readability have already done the work that lawful intake, lawful source use, lawful transition checking, and lawful standing review still require.

This file exists to make those review questions explicit without pretending that admissibility is one universal one-step switch.

## 4. What Admissibility Review Answers

Admissibility review answers the bounded operational question:

**May this material, source, transition, or pressure lawfully proceed in the claimed way at the claimed rank?**

That question is not:

- “is this good?” in the abstract
- “is this persuasive?” in the abstract
- “does this settle everything?” in the abstract

It is a bounded review question about lawful proceeding, lawful use, lawful relation, and lawful pressure at the rank actually being claimed.

Admissibility review is therefore not final closure.

It is also subdomain-sensitive. A material may pass one admissibility question and fail another. For example:

- something may be admissible for intake while inadmissible as source
- something may be admissible as source while inadmissible as standing pressure
- something may be admissible to press toward review while inadmissible to present itself as already closed

## 5. Core Review Questions

Whenever admissibility is being claimed, the following questions should be made explicit.

1. What is the object under review?
2. What class of object is it?
3. What rank is being claimed for it?
4. What relation is being preserved or asserted?
5. What surface or law supports the claim?
6. What does this object become if admitted for this bounded use?
7. What does it explicitly not become?
8. Is the lineage visible enough to recover the claim honestly?
9. Is the matter fit lawful?
10. Is source admissibility relevant here, and if so, has it been satisfied?
11. Is the material pressing toward further review or admission, or is it falsely presenting itself as already closed?

These questions are procedural rather than decorative. They keep admissibility review explicit enough that later readers can see what is being allowed, what is not being allowed, and what collapse path is being refused.

## 6. Object Class and Rank Review

Admissibility review must identify object class and claimed rank explicitly.

The current body already supports at least the following kinds of object reading:

- candidate material
- preserved artifact
- derivative readability surface
- proof-bearing output
- source-side evidence or lineage surface
- admissible derivation surface
- transition request or crossing claim
- standing-facing review pressure
- canon-facing admission pressure

The current body also already supports rank distinctions such as:

- constitutional source artifact
- machine-readable constitutional canon
- authoritative runtime participant or bounded validator output
- source-side authoritative inheritance
- source-side evidence and lineage only
- v1 derivation surface
- preserved run artifact
- derivative readability surface

Rank confusion is one of the main collapse paths. If object class or claimed rank remain vague, preserved evidence can begin to impersonate authority, readability can begin to impersonate canon, and derivation can begin to impersonate final standing.

## 7. Relation, Matter, and Source Review

Admissibility review must preserve relation fit, matter coherence, and source admissibility where relevant.

This means review should ask:

- what relation is actually being claimed
- whether the object fits that relation lawfully
- whether the matter relation is coherent rather than atmospheric
- whether lawful source use has been established where source use is part of the claim

These questions do not disappear just because something is readable, proof-bearing, preserved, or recent.

Readable material may still be the wrong source.

Proof-bearing material may still be the wrong relation.

Preserved lineage may still be the wrong matter fit.

This file therefore stays adjacent to source admissibility without collapsing into a source-only note.

## 8. Pressure, Admission, and Closure Review

Admissibility review must preserve the distinction between:

- visible material
- review pressure
- admission pressure
- final standing
- canon
- constitutional force

In many cases, admissibility review governs what may proceed further rather than what has already closed.

That means review should ask whether the object:

- is only visible
- lawfully creates pressure for further review
- lawfully creates pressure for bounded admission consideration
- or is falsely presenting itself as though standing, canon, or force has already been achieved

This matters especially in the current body because preserved proof, preserved readability, admissible derivation, and visible lineage are all stronger than they were earlier, but they still do not resolve final closure automatically.

## 9. Cross-Domain Anti-Collapse Rules

A conforming admissibility review posture must preserve the following rules explicitly.

- encountered is not accepted
- accepted is not scoped
- scoped is not truth
- threshold is not standing
- preserved is not source
- source is not admissible source by default
- admissible source is not authoritative source
- proof-bearing is not doctrine by default
- readability is not authority
- visible lineage is not standing admission
- admissible derivation is not final standing
- canon-facing pressure is not canon already achieved
- passed validation is not governance authorization
- carried arrival is not native standing by arrival alone

These are not slogans. They are the minimum anti-collapse protections that keep admissibility review honest across domains.

## 10. What Review Does Not Grant

A satisfactory admissibility review does not itself create:

- truth
- final standing
- canon
- constitutional force
- publication rank
- governance authorization

It also does not settle all other admissibility domains automatically.

Passing one domain’s review does not settle the others.

Passing a checklist does not replace doctrinal judgment, rank reading, source reading, or standing review.

## 12. Closing Boundary Statement

This file defines admissibility tests and anti-collapse rules only.

Later files may elaborate other admissibility domains or domain-local procedures. This file does not resolve doctrinal disputes automatically, and it does not turn the checklist into sovereignty.

It exists so admissibility can be reviewed explicitly inside the IAMMAI body without inflating the checklist into final judgment or collapsing the ranked body into atmosphere.
