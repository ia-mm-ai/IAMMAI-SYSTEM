# IAMMAI Stress Test Matrix v0

## 1. Purpose

This file defines the first bounded pressure-testing matrix for IAMMAI.

Its job is to explain what `going harder` means lawfully in the current body, what kinds of pressure are allowed in the next local test phase, what must remain invariant while pressure increases, what counts as a repeating seam rather than random noise, what stop conditions should prevent reckless escalation, and what evidence would justify later translating regulation into embodiment or runtime.

It does not yet try to define:

- code
- a fuzzing spec
- a public test plan
- a chaos-engineering document
- a broadened embodiment slice
- a runtime regulation subsystem

It is a bounded embodiment and dynamics bridge document.

## 2. First Principle

Stress testing must remain bounded by the constitutional core.

Pressure must increase without widening the slice class.  
The purpose is to reveal lawful seams, not to create spectacle.  
Visible failure remains preferable to false continuity.

In IAMMAI terms, `going harder` does not mean random escalation. It means increasing bounded pressure inside the same lawful local note slice until repeating seams either appear clearly or fail to appear under disciplined repetition.

## 3. Why a Stress-Test Matrix Is Needed

The current body is now strong enough to be pressure-tested because it has already completed lawful local runs, shown repeatability, preserved visible non-passage, entered controlled variation, and begun continuity accumulation.

Pressure should be staged rather than improvised. Without a bounded matrix, the body could confuse seriousness with escalation, broaden scope in order to look stronger, or treat one awkward outcome as reason either to panic or to redesign prematurely.

This phase therefore sits between repeatable embodiment and any future regulation translation. It exists to see whether the current body remains lawful under more pressure, or whether recurring seams now become clear enough that regulation can no longer remain only conceptual.

Stress testing must not become broadening by another name. If the test pressure requires a larger slice, richer matter class, broader access surface, or public exposure, it is no longer this phase.

## 4. What Remains Invariant During Stress Testing

The following must stay the same across all v0 stress-test levels:

- matter class remains bounded local note
- same runtime role family remains in play
- same canonical artifact family remains in play
- same local execution boundary remains in force
- same canonical versus derivative separation remains in force
- same continuity emission posture remains in force
- same non-public local-first posture remains in force

More concretely, stress testing does not permit new matter categories, richer embodiment classes, public interaction, multi-party surfaces, historical artifact ingestion, product logic, or silent changes to the success path artifact structure.

## 5. Allowed Pressure Dimensions

The allowed pressure dimensions for v0 are conservative and local:

- wider but still bounded note variation
- cleaner single-cause invalid matters
- borderline-valid matters near the slice edge
- repeated sequential runs
- continuity accumulation across more runs
- modest operator load

These pressure dimensions remain lawful because they test the current body more intensely without changing what kind of body it is. They increase repetition, edge handling, and continuity burden while keeping the same slice identity intact.

## 6. Pressure Levels

The first bounded pressure ladder for v0 is:

- Level 1: more valid bounded notes across the same local note style
- Level 2: clean single-cause invalid cases that preserve the same intended matter class
- Level 3: borderline-valid cases near the slice edge without widening matter class or adding richer ontology
- Level 4: repeated sequential runs across mixed valid and invalid bounded matters
- Level 5: continuity accumulation under repeated successful bounded runs with the same emission posture and truthful failure handling alongside it

This ladder is intentionally small. Each level increases pressure by repetition, edge proximity, or continuity burden rather than by architecture change.

Progression should remain staged. Later levels should not be treated as lawful merely because earlier levels once passed. The current body should be read at each level for recurring seams, not only for headline success count.

## 7. What Counts as a Repeating Seam

A repeating seam is a recurring weakness that appears across turns, bounded matters, or pressure levels and keeps pressing the same lawful boundary.

The following would count as real repeating seams rather than random noise:

- the same role-boundary softening recurring across runs
- the same ambiguity requiring manual rescue repeatedly
- the same failure-handling weakness recurring under different bounded matters
- continuity emission beginning to outrun preserved artifacts
- controlled variation repeatedly pressuring slice identity rather than staying within it
- the body staying lawful only through operator elegance rather than embodied clarity

A seam matters when the same kind of pressure keeps producing the same weakness despite remaining within the same bounded slice. That is different from a single awkward artifact or one surprising run outcome.

## 8. What Does Not Yet Count as a Regulation-Triggering Seam

The following should not immediately justify regulation translation:

- one isolated failed run
- one awkward artifact
- one surprising but bounded outcome
- one operator uncertainty
- one edge case that does not repeat

These may still deserve observation, but they do not yet show that the body cannot honestly proceed without tighter embodied regulation. A regulation-triggering seam requires recurrence, not isolated discomfort.

## 9. Stop Conditions

The stress-testing phase should stop if any of the following conditions begin to hold:

- pressure begins widening the slice class
- public exposure pressure appears
- repeated drift signals emerge in the same family
- canonical versus derivative separation weakens
- continuity truthfulness weakens
- manual rescue becomes the main reason the body still appears lawful

These stop conditions exist to prevent reckless escalation. The phase should also stop if pressure begins to demand broader matter categories, hidden role shortcuts, cosmetic smoothing of non-passage, or convenience rewriting of prior turns.

## 10. What This Phase Is Trying To Prove

This phase is trying to show:

- whether the current body remains lawful under more pressure
- whether regulation may stay conceptual longer
- whether repeated seams now justify bounded regulation translation later

The decisive evidence would not be louder activity. It would be one of two things.

If the body continues to preserve role distinction, visible non-passage, truthful continuity, anti-overwrite posture, and slice identity under staged pressure, that is evidence that regulation may remain architectural for longer.

If recurring seams appear across bounded matters and repeated runs, especially in the same seam family, and if the body increasingly depends on operator rescue rather than embodied clarity, that is evidence that later regulation translation into embodiment or runtime may become justified.

## 11. Relation to Future Steps

If the body holds, continue bounded local pressure and audit.

If repeating seams emerge, reassess whether regulation needs embodiment or runtime translation.

Drift and stability should be read through the results of this phase, because this phase is where recurring seam families become visible enough to support or block later stability claims.

Adaptation remains guarded and out of play for now. This matrix is not an adaptation license. It is a bounded way to test whether the current body can carry more pressure honestly before any deeper change is considered.

## 12. Summary

This document defines the first bounded stress-test matrix of IAMMAI as the staged local framework for increasing pressure within the same bounded local note slice so repeating seams can become legible without widening the body, smoothing failure, or outrunning preserved canon.

Its purpose is to keep pressure testing disciplined enough that the results can later support one of two lawful conclusions: either the current body remains strong enough for regulation to stay conceptual longer, or recurring seams have become clear enough that bounded regulation translation should be considered.
