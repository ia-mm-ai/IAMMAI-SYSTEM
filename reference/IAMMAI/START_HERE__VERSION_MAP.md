# IAMMAI Version Map

This repository should be read as a lineage-bearing body, not as one flat surface.

The current root tree is the frozen IAMMAI v0 source-side body. It remains legible as the line that was actually formed, including its proof, drift, experiments, and corrections in place as history rather than as retroactive cleanup.

A later `v1/` may be opened beside root as a new admissible derivation line. If that happens, it should be read as a later line next to the frozen root tree, not as a silent replacement of it.
