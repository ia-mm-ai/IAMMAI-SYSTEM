# IAMMAI Current Continuity Surfaces

## 1. Purpose

This file is a bounded re-entry and surface-map note for the continuity area as it stands now.

Its job is to reduce continuity re-entry drift by stating, in one compact place:

- what the continuity area is currently centered on
- what continuity surfaces remain foundational context
- what newer first-pass continuity-housing objects now stand
- what remains explicitly open

It does not:

- define a constitutional rewrite
- define a continuity-family master map
- define a storage architecture
- define a graph or database design
- define a distributed systems plan
- define a schema
- replace continuity, current-state, readability, admissibility, accession, standing, vessel, bridge, or review surfaces already standing in the body

This file is additive only. It does not replace `CURRENT_STATE__REPO_ENTRY.md`, `CURRENT_READABILITY_SURFACES.md`, `RANKED_SURFACE_INDEX.md`, the continuity architecture files, the first-pass objecthood files, or the nearby `v1/` bridge and review surfaces.

## 2. Why This Note Is Needed Now

Continuity has become rich enough that re-entry can now drift without one bounded continuity-centered surface map.

Older foundational continuity architecture and newer continuity objecthood now coexist in the same area. Without one compact note, a later reader can too easily flatten seam-law context, continuity-turn framing, emission discipline, bridge carry, lineage objecthood, and currentness objecthood into one undifferentiated continuity story.

The body therefore needs one small note that reduces continuity remembering burden without opening a new family. The current continuity area is no longer centered only on architectural framing. It is now also centered on first-pass practical objecthood for lineage and operative currentness.
