# Seam Rule

## 1. Purpose

This experiment tests the first tiny lawful seam crossing for one existing artifact.

It does not test code, schema, bidirectional exchange, governance crossing, or automatic re-instantiation.

## 2. First Seam Rule

One artifact may cross.

Source canon remains at source.  
The destination may receive only as candidate or derivative.  
The destination must not treat the artifact as native standing, truth, or authority by default.

## 3. What Must Remain Visible

- source legibility
- artifact type
- origin relation
- transfer decision: accepted or rejected

## 4. Acceptance Conditions

- source is legible
- type is legible
- no silent authority transfer
- destination treatment remains bounded

## 5. Refusal Conditions

- missing source legibility
- missing or unclear type
- implied authority crossing
- implied native standing at destination

## 6. What This Note Does Not Do Yet

- no code
- no schema
- no bidirectional exchange
- no governance crossing
- no automatic re-instantiation
