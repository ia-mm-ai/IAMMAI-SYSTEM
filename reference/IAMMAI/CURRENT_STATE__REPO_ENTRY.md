This repository should still be read in ranked layers rather than as one flat surface.

- Root is the preserved source-side lineage body. It remains the historically real v0 line and is not replaced by adjacency.
- `v1/` is the active admissible derivation line beside root. It carries explicit re-derivation, preserved executed proof, and later transfer-account entries under the new line.
