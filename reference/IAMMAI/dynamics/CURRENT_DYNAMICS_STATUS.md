## 2. Why This Note Is Needed Now

The dynamics area already has conceptual order and bounded doctrine.

What it has lacked is one compact note showing where regulation, drift, stability, and adaptation already have visible evidence in the present body. Without that note, dynamics remains too easy to read as a conceptual sidecar rather than as a derivative layer now being justified by actual motion, visible pressure, and bounded non-closure already standing in the repository.

This file exists to reduce re-entry burden inside `dynamics/` without opening a new family.

## 3. Dynamics Order That Already Stands

The current dynamics order already stands as:

- regulation
- drift
- stability
- adaptation

That order is already explicit in `dynamics/`. Regulation asks how lawful motion remains bounded under pressure. Drift asks where repeated motion departs from lawful form. Stability asks what lawful steadiness would mean across repeated turns. Adaptation remains the most guarded concept and enters last.

This note does not change that order. It binds it to current evidence.

Current body evidence supports that caution:

Adaptation therefore remains future, conditional, and bounded. It is not the active center of the current body.
